## Short description (132 characters max)

Shows your public IPv4 and IPv6 addresses with one-click copy buttons.

## Description

IP Address Viewer shows your public IP addresses in a single click:

- Public IPv4 address
- Public IPv6 address, when available
- Copy each address to the clipboard with one click
- Refresh button to fetch the current addresses
- Real-time status indicator per address
- English and Spanish interface, light and dark mode

The addresses are obtained from the free ipify.org API. The extension does not
collect, store or transmit any personal data.

## Single purpose

IP Address Viewer shows the user's public IPv4 and IPv6 addresses with a button
to copy each one.

## Permission justifications

**Host permission (api.ipify.org, api64.ipify.org)**
Query the ipify.org API to obtain the public IPv4 and IPv6 addresses. No other
host is contacted and no user data is sent.

**Remote code**
No, I am not using remote code. All HTML, CSS and JavaScript is included in the
package.

## Data usage

No user data is collected or stored. The only network request is to ipify.org to
read the public IP address, which is displayed in the popup and never sent
anywhere else.
